  Durante o desenvolvimento dos projetos deste repositório, foram aplicados e consolidados os seguintes conceitos:

  ## 🚀 Projetos e Atividades Desenvolvidas
  
  Abaixo estão as atividades documentadas neste repositório, com os respectivos aprendizados técnicos:
  
  ### 📰 1. Portal de Notícias: "O Paulistano"
  * **Arquivos:** `index.html` e `styles.css`
  * **Descrição:** Uma interface completa de um portal de notícias regional. O foco desta atividade foi a **semântica** e a **arquitetura de layout**.
  * **Destaques Técnicos:** 
    * Uso de tags semânticas do HTML5 (`<header>`, `<main>`, `<section>`, `<article>`, `<nav>`) para melhorar a acessibilidade e o SEO.
    * Implementação de **CSS Grid** (`display: grid`) para posicionar as matérias jornalísticas como em um jornal impresso real, criando um mosaico perfeitamente alinhado.
    * Estilização de tipografia importada do Google Fonts, variáveis CSS (`:root`) para padronizar as cores do projeto e efeitos de transição (Hover) nos cartões de notícias.
  
  ### 📱 2. Atividade 5: Media Queries e Responsividade
  * **Arquivos:** `index1.html` e `style1.css`
  * **Descrição:** Um estudo prático sobre **Design Responsivo**. A tela exibe uma caixa centralizada cujo comportamento e cor mudam dependendo do tamanho da tela do dispositivo.
  * **Destaques Técnicos:**
    * **Analogia:** Pense na responsividade como a água, que toma a forma do recipiente onde é colocada. 
    * Uso de `@media` queries atuando como "sensores". O CSS escuta a largura da tela (`max-width` e `min-width`) e, dinamicamente, altera o CSS (do fundo cinza em celulares pequenos, até o verde em monitores ultrawide).
  
  ### 🧮 3. Lógica com JavaScript: Calculadora de Média
  * **Arquivos:** `Media.html` e `media.js`
  * **Descrição:** Minha primeira introdução à interatividade e algoritmos no navegador. O programa interage com o usuário, coleta dados e devolve uma resposta processada.
  * **Destaques Técnicos:**
    * Uso de `prompt()` como os "ouvidos" do programa (coletando notas) e `alert()` como a "boca" (exibindo o resultado).
    * Conversão de dados com `parseFloat()` para garantir que o texto digitado seja tratado como número real, permitindo cálculos matemáticos.
    * Formatação de saída elegante com `.toFixed(2)` para limitar as casas decimais.
  
  ### ➕ 4. Lógica com JavaScript: Operações Matemáticas
  * **Arquivos:** `Operacoes.html` e `operacoes.js`
  * **Descrição:** Um script focado em consolidar o entendimento dos operadores aritméticos fundamentais da programação.
  * **Destaques Técnicos:**
    * Demonstra a manipulação de variáveis para executar soma (`+`), subtração (`-`), multiplicação (`*`), divisão (`/`) e a obtenção do módulo/resto da divisão (`%`).
    * Utilização de concatenação de strings avançada com `\n` para quebrar linhas e montar um relatório limpo no alerta final.

  ## ⚙️ Como Executar os Projetos
  
  1. Clone este repositório para sua máquina local.
  2. Abra a pasta do projeto no **Visual Studio Code**.
  3. Para as interfaces (como o portal de notícias ou a caixa responsiva), abra os arquivos `.html` no seu navegador.
  4. Para as lógicas de JavaScript, ao abrir o `.html` respectivo, o próprio navegador executará os *prompts* e *alerts* automaticamente!
     > *Dica:* Utilize a extensão **Live Server** no VS Code para ver as alterações de layout em tempo real!
